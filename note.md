Web Design Project
Create a website with a certain theme (e.g. Bakery, Movies, Personal Portfolio, etc) 
based on the following requirements without sacrificing aesthetics!


1. Minimum 5 different pages (5 different HTML files), and all of them must be interconnected with each other. 
The 5 pages must be connected with navigation and other parts.


2. Minimum of 5 CSS properties for each of the following. You must use all three methods of using CSS 
(inline, style tag, and separate files) in the project!
a. Background Properties
b. Text and Font Properties
c. Dimension Properties
d. Positioning Properties


3. There must be at least one set of form and validation in one page consisting of
a. Text Input
b. Password Input
c. Text area
d. Radio
e. Checkbox
f. Selection
g. Submit Button

4. In one or more page, provide at least 1 table, 2 ordered list and 2 unordered list
